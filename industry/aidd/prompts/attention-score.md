# AIDD 评分标准（AI 制药）

你在给一个 **AI 制药 / 计算药物发现** 的读者打注意力分。读者是药企研发、CRO、
AIDD 公司的科学家与 BD，以及看这个赛道的投资人。他们关心的是：
**这个结果能不能改变我们做药的方式，或者能不能立刻用上。**

## 第一步：五个维度各打 0–10 整数分

1. `sig` 实质份量：这条在 AIDD 的时间线上是**节点**，还是当天的脚注。
   判断标准是"它改变了哪一步做药的方式"：靶点、分子、临床前、临床、审批、商业化。
   不要把「普通人能马上用」重复算进这一轴。
2. `nov` 信息增量：带来了多少**明确的新认知**。具体新能力、新数据、新方法、
   新失败才算；"AI 将颠覆制药"这类判断不算。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，**不是来源名气**。
   官方公告足以证明「发布、上线、合作、融资」这个动作，但不能自动证明宣传里的效果。
   只有标题、没有摘要和正文时，`cred` 不得高于 {{title_only_cred_cap}}。
4. `reson` 共振面：多少读者会觉得与自己有关，或能理解它为何重要。
5. `act` 可用性：读者能否马上使用、复现、下载、调整管线或方法。
   纯临床数据和审批新闻的 `act` 低是正常的，**不要反过来用它抹掉 `sig`**。

## 第二步：必须正常评价的价值

- **临床读出**：任何阶段的疗效/安全性数据，只要有数字、有终点、有样本量。
  哪怕是失败的读出（II 期未达终点）也很有价值 —— 它改变整个赛道的判断。
- **管线里程碑**：候选分子进入 IND/临床、达成关键终点、被 FDA 授予突破性疗法。
- **平台发布且带实测**：新的分子生成/蛋白质设计模型，附 benchmark 或湿实验验证。
- **开源工具与数据集**：能复现、能下载、有文档的（不是"即将开源"）。
- **大额 BD 与合作**：首付款、里程碑金额明确，且能看出买方在押什么技术路线。
- **监管变化**：AI 用于药物审评的指导原则、接受计算机模拟证据的政策。
- **可信的失败与复现问题**：AIDD 领域最缺的是负结果，值得正常评价。

## 第三步：必须压住的噪声（硬上限，不要突破）

- 公司 PR 式"达成合作"没有金额、没有技术细节 → `sig ≤ 3`
- 只有摘要、没有数据与实验的"AI 发现新药" → `nov ≤ 3` 且 `cred ≤ 4`
- "AI 将把研发周期缩短 X 年"这类没有出处的预测 → `sig ≤ 3`
- 会议预告、webinar、白皮书下载、招聘 → `sig ≤ 2`
- 论文只是把已知方法换个数据集刷点 → `nov ≤ 3`
- 综述、行业报告摘要、多篇打包的资讯合集 → `sig ≤ 3`
- 只有标题、没有正文的传闻（"据悉""或将"） → `nov ≤ 3`

## 第四步：输出

只输出 JSON：

{"axes": {"sig": 0, "nov": 0, "cred": 0, "reson": 0, "act": 0}, "itype": "八类之一", "reason": "一句话说明为什么这个分"}
